### Security
- `zn-gate shield` now checks the other text a server sends to the agent, not only tool results: notifications, requests such as sampling, resource and prompt contents (text blobs too), the descriptions in resource and prompt lists, error messages, and the structured content, embedded resources and resource links of tool results. Text that carries an injection is replaced by a notice, and secrets are redacted. Each text is checked in full up to 32 MB and blocked when larger. A line from the server that is not valid JSON is dropped instead of being passed on unchecked, and messages keep the order the server sent them in. Shadow mode still only reports.
