### Added
- `zn audit --pre-open` checks a cloned folder for things that can run before an agent asks you to trust it, and runs all the usual checks too. Three new rules: ZNA024 (a git config that makes git run a program or load a file from the folder: `core.fsmonitor`, `core.sshCommand`, `core.pager`, `core.editor`, external diff and merge tools, filter drivers, credential helpers, `core.hooksPath` or an include that points into the folder), ZNA025 (a bare git repository nested in the folder) and ZNA026 (a program in `bin` or `.bin` named like a common tool). The git config is read as text without running git, links are not followed out of the folder, and reports name the setting and line, never its value. It is a pre-check, not protection.
