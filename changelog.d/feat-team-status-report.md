### Added
- A machine in a Team organization now sends a short status report after each sync, so the dashboard can show machines that run an old zn-gate or have broken hooks: the zn-gate version, the OS family, the version and state of the organization policy (`active`, `expired`, `refused` or `none`), and for each agent whether its zn hooks are `ok`, `stale` or `broken`. It never holds paths, host names, user names, secret names or prompts. The `zn team join` dialog now lists it. A machine that joined before this version sends nothing until you run `zn team status-report accept` once (a dialog on the vault's own channel asks you); `zn team status-report stop` turns it off. `zn team status` shows whether it is on and the exact last report with its time. Outside a Team organization, after `zn team leave` and after removal by an admin, nothing is sent.
