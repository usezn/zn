### Security
- The library checks (the Python and Node.js APIs) now protect the same credential files as the hook. Before, only .env files, SSH private keys, authorized_keys and ~/.aws/credentials were refused, so a shell tool guarded only by the library could read ~/.npmrc, ~/.pypirc, ~/.netrc, ~/.git-credentials, ~/.pgpass, the Docker, GitHub CLI, Kubernetes, Google Cloud and Azure credential files or a GnuPG folder file. A project-level .npmrc is still allowed, as in the hook. The library also reads the bash locale quote, so cat ~/.ssh/$"id_ed25519" is refused like the plain form.
