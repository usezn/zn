### Security
- The library checks (the Python and Node.js APIs) now refuse the named credential files that the hook refuses. Before, only .env files, SSH private keys, authorized_keys and ~/.aws/credentials were refused, so a shell tool guarded only by the library could read ~/.npmrc, ~/.pypirc, ~/.netrc, ~/.git-credentials, ~/.pgpass, the Docker, GitHub CLI, Kubernetes, Google Cloud and Azure credential files or a GnuPG folder file. A project-level .npmrc is still allowed, as in the hook. The library also reads the bash locale quote, so cat ~/.ssh/$"id_ed25519" is refused like the plain form. The library still does not cover everything the hook does: it does not find key files by their content (.pem, .key, .p8), certificate containers by extension (.p12, .pfx) or files named by an environment variable, so use the hook where those matter.
