### Security
- Claude Code: a `secrets` server defined in a project's `.mcp.json` or in a local-scope entry is now also found when the hook runs in a folder outside the project (one added with `--add-dir`), from the project folder Claude Code names, and on Windows whatever the case of the folder name. Such a server is checked like any other and never receives a `__ZN_` marker.
- Claude Code: the user-scope `secrets` server is no longer taken as zn's when its entry sets `NODE_OPTIONS` or `NODE_PATH`, or a folder inside the project to run in. The MCP server names of the zn-gate plugin are no longer trusted either: the plugin registers no MCP server since 1.14.0, and an older plugin started its servers with `node` from the `PATH`.
