### Fixed
- `zn-gate scan` and `zn-gate audit` (and `zn-gate scan` in the Python package) no longer skip build and vendor directories without a word. The directories they do not enter are now listed with a reason: a count in the text and GitHub output, and `skipped_dirs` in the JSON output (`audit` lists them in its text report and as `skippedDirs` in its JSON). A directory named `target` is skipped only when a `Cargo.toml`, `pom.xml`, Gradle or sbt build file sits next to it, and `vendor` only next to `go.mod`, `composer.json`, `Gemfile` or `Cargo.toml`; otherwise it is read like any other directory. The directory you pass to `scan` is always read, whatever it is called.
