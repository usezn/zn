### Added
- Experimental: `zn hooks install antigravity [--project]` adds a pre-execution hook for Google Antigravity (`.agents/hooks.json` in a project, `~/.gemini/config/hooks.json` for your user). It blocks the agent from reading or writing secret files by path, and from running shell commands that handle secrets, and it protects its own hook files from edits by the agent. Searches across a folder ask for confirmation when the folder itself holds a plain-text `.env` or key file, but matching lines and command output are not redacted, because Antigravity hooks cannot rewrite tool output. Antigravity does not document what happens when a hook fails. `zn-gate check` reports the Antigravity hook, and `zn-gate init` also looks for a project `.agents/mcp_config.json`.
