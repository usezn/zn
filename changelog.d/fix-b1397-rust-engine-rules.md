### Fixed
- Experimental Rust gateway (not distributed): its rules now agree better with the Node.js and Python rules. Command words such as `format` and `chmod` are only checked in tool calls, not in text sent to the analyzer. A text with a bidirectional override character is blocked (`evasion:bidi_override`). A bare `jailbreak` is a warning unless the new `managed_rules.strict_prompt_injection` setting is on. Accent marks, Greek and mathematical look-alike letters, URL escapes, HTML entities, shell quoting and simple shell variables no longer hide a phrase or a command, a Base64 payload that a command decodes is checked, and the secret scrubber also redacts `client_secret`, `private_key`, `passwd` and `aws_secret_access_key` values.
