### Security
- Node.js library: `redactSecrets` and `sanitizeToolResult` could leave a provider key, such as a Stripe key, unredacted when a wider match of another kind covered it (for example `key: sk_live_...` followed by `NAME=` on the same line, or a GitHub token running into the next line). The provider formats are now matched on their own, as in the Python package. A CI test redacts seeded random texts of fake keys with both packages and fails if either package leaves a key in the output.
