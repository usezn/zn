### Security
- Python: a tool result holding plain objects with more than 100,000 attribute names and values, about 50,000 attributes (for example JSON read into a custom class with `json.loads(..., object_hook=...)`), had the values past that limit skipped without being checked. Such a result is now blocked (rule `size:items`), as it is for dicts and data models. Arguments passed to `@guard` keep reading application objects best effort.
