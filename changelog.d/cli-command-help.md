### Added
- Every `zn-gate` command has its own short help: `zn-gate <command> --help` and `zn-gate help <command>` print what the command does, its options, an example and its exit codes, and `zn-gate help` is the general help. `zn-gate` with no arguments prints a five line start (`init`, `check`, `reach`, `--help`) instead of the whole help.
