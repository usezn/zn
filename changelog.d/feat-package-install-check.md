### Added
- Optional check of the packages your agent installs by name (`npm install`, `pnpm add`, `yarn add`, `bun add`, `pip install`, `uv add`, `pipx install`). It is off by default and never blocks a command: with `hooks.packageInstallCheck` set to `"offline"` in `~/.zn/config.json` (or `ZN_PACKAGE_CHECK=offline`), your agent asks before it installs a name that looks like a well-known package (one letter off, two letters swapped, a look-alike character, other separators, or an npm scope that imitates a well-known one), using a list that ships with zn-gate and no network. With `"online"` (config file only), zn-gate also asks the public npm or PyPI registry, with only the package name, whether the name exists and is not brand new, and asks when it does not exist or was first published less than 14 days ago (`hooks.packageInstallNewDays`). Names you trust go in `hooks.packageInstallAllow`. Agents that cannot show a question (Codex CLI, OpenCode, Gemini CLI) run the command, and every finding is written to the decision log. See [Packages your agent installs](docs/package-install-check.md).
