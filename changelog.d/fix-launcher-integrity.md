### Security
- On macOS and Linux, and for Claude Code on Windows (which runs the same launcher through Git Bash), zn's hook launcher now runs zn-gate's hook runner only while that file still has the SHA-256 recorded at install time, and no longer falls back to a `zn` found on the PATH. The Node.js recorded at install time reads the runner once, checks it and runs that same content, so no program on the PATH takes part in the check. A runner that was edited or swapped for a stub is blocked with a message to run `zn hooks install <agent>` again, and `zn-gate check` reports it. The check covers the runner file, not the other files of the package. The inline PowerShell hooks of Codex CLI, Cursor, Gemini CLI and Antigravity on Windows are unchanged. Updating zn-gate (`npm update -g zn-gate`) refreshes the launchers it wrote, on Windows too. If the update does not run install scripts (`--ignore-scripts`, or pnpm and bun, which skip them by default), run `zn hooks install <agent>` again; until then the hooks block tool calls and tell you to do so.
