### Added
- After you run `zn-gate connect` (environment variables alone do not enable this, because a project can set them; the hook uses only the saved key), the Claude Code hook now also sends a sample of the results of web fetches, MCP tools and shell commands to the zn cloud to look for hidden instructions aimed at the agent. This is new: until now tool output never left your machine. The sample is at most 16 KiB, counted in bytes of UTF-8 text (the first 12 KiB and the last 4 KiB), is sent only after secrets and personal data (email addresses, phone numbers, IBANs and card numbers) are removed, skips a result the local check already flagged, and goes only to `api.usezn.com`. The cloud answer can only add the note the local check adds; if the call fails nothing is blocked or changed. Without `zn-gate connect` nothing is sent. Other agents send nothing. `{"hooks": {"cloudCheckToolOutput": false}}` in `~/.zn/config.json` turns off just this path and keeps the prompt check.

### Changed
- The data-flow notes in the READMEs and docs now say that tool output is sent in this one opt-in case.
