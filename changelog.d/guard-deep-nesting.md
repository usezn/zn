### Security
- Tool arguments or tool results nested more than ten levels deep were passed through without being checked, so a value hidden that far down skipped every rule. Dicts, lists, data models and namespaces nested deeper than that are now blocked with the reason "nested too deeply to check" (rule `size:nesting`); other objects in a tool result are read up to 32 levels and blocked past that, and `@guard` reads application objects passed as arguments best effort. Mapping types other than a plain dict, frozensets and byte strings are now scanned as well, and a structure that contains itself no longer loops. Affects 1.13.1 and earlier of the Python package.
