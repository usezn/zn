### Security
- The pre-tool check now looks inside a folder given to `tar`, `bsdtar`, `zip`, `7z`, `cp`, `rsync` or `scp`, and refuses the command when the folder holds a file zn protects: a `.env` with values, a credential file such as `~/.ssh/id_ed25519` or `~/.aws/credentials`, or a private key. Before, `tar czf k.tgz ~/.ssh`, `zip -r k.zip ~/.aws` or `cp -r ~/.ssh /tmp/x` were allowed while the same command with one of those files was refused. The look goes level by level, up to 3,000 entries and one second, and skips package and cache folders; a larger folder asks you first. Folders of ordinary files (`tar czf src.tgz ./src`, `cp -r ./build ./out`) and reading or extracting an archive (`tar xzf k.tgz`, `7z x`) are not affected.
