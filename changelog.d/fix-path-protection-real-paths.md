### Security
- The agent hooks protect `~/.zn` and the agents' plugin folders also when they are reached another way: through the real path of a linked home folder or project, after `cd ~` (or `cd`, `cd $HOME`, `env -C ~`, `git -C ~`) followed by a relative path, through a variable the command sets itself (`X=$HOME; rm -rf $X/.zn`), one that is not set or that is set from another command's output (`X=$(echo ~)`), through a command substitution (`$(echo ~)/.zn`) and through another user's `~name`. A `find` that deletes (`-delete`, `-exec`) from the home folder or above it and names these folders is refused too. A home folder of `/` is handled. Before, these writes and deletes were allowed.
