### Changed
- `zn-gate check` and `zn-gate doctor` now use plain words. With no coding tool on the machine they say "No AI coding tool was found on this computer ... nothing to check yet" and point to the setup guide. The speed line reads "Time zn takes to decide" (a typical time, and the time that 19 in 20 actions stayed within) instead of "Decision time per tool call" with p50 and p95. For Claude Code that is not set up, the text tells you to run `npx -y zn-gate init` instead of printing the plugin commands, and a tool that is not installed no longer shows "version: not found". The last line about hooks reads "Hooks: N working, N out of date, N need repair". `zn-gate check --hooks` explains a settings file it cannot read without the word JSON, says that zn has not changed it, and tells you to repair it first: `zn hooks install` stops without changing such a file, and once the file is valid it saves a backup copy and keeps your other settings. The `--json` output and exit codes are unchanged.
