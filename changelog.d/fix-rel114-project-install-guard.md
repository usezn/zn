### Security
- A project install (`zn hooks install <agent> --project`) for Claude Code, Codex CLI, Cursor, Gemini CLI and GitHub Copilot CLI wrote a bare `zn hook <agent>` command. Where `zn` or Node.js could not start (not installed on a teammate's machine, a Node.js version removed), that command failed with exit 127 and the agent ran the call unchecked. The project hook now runs `zn` from the PATH inside a small start guard, the way Antigravity project installs already did: if `zn` or Node.js is missing, or the hook fails, the guard answers with that agent's own block (exit code 2 with the reason, or the deny answer) on the events that can block, and only warns on the others. The command has a POSIX `sh` form and, for Codex, Cursor, Gemini CLI and Copilot on Windows, a PowerShell form with no cmdlets. `zn-gate check` now reports a bare `zn hook <agent>` in a project file as NOT protected; run `zn hooks install <agent> --project` again in that project to replace it.
