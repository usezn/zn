### Added
- Experimental: `zn hooks install gemini [--project]` adds a pre-execution hook for Gemini CLI (`~/.gemini/settings.json` for your user, `.gemini/settings.json` in a project). It blocks the agent from reading or writing secret files by path and from running shell commands that handle secrets, and it protects Gemini CLI's own settings files from edits by the agent. Gemini CLI hooks cannot ask for confirmation, so a call zn would ask about is blocked with its reason, and a hook that crashes or times out does not block the call (only an explicit refusal, exit code 2, does). `zn-gate check` reports the Gemini CLI hook, and warns when `hooksConfig.enabled` is false or zn's hook is listed in `hooksConfig.disabled`.
