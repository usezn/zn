### Security
- The library checks (the Python and Node.js APIs) now read a protected file name that a shell command builds instead of writing it out. Before, a command such as F=.env; cat $F, cat ${UNSET:-.env}, cat ~/.ssh/$KEY, cat ~/.s*/id_ed25519, cat .e*, cat .en{v,}, find . -name '.e*' -exec cat {} +, cat .e$(printf nv) or cat $'\x2eenv' could read .env files, SSH private keys or the other protected credential files when a shell tool was guarded only by the library. The library now replaces simple assignments, defaults, echo and printf substitutions and escape bytes by their values, turns globs and braces into patterns, and refuses a command when a pattern can match a protected name. Globs that only match other files, such as *.md, ~/.ssh/*.pub or .env.example, are still allowed.
