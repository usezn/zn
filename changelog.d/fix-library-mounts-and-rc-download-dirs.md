### Security
- The library checks (the Python and Node.js APIs) now read container volume and mount specs the way the hook does. Before, docker, podman and nerdctl commands such as docker run -v ~/.ssh:/root/.ssh img, docker run -v $HOME/.aws:/a img or docker run --mount type=bind,source=$HOME/.ssh,target=/k img could share the SSH or AWS credential folders with a container, and a dotenv file named in --mount source=.env, when a shell tool was guarded only by the library. They are now refused; other mounts such as ./data:/data are still allowed.
- The download rule for shell startup files now reads the folder options of curl and wget. Before, curl --output-dir ../etc -O URL, wget -P ../etc URL (for a file named zshenv or profile), curl --create-dirs -o ../etc/profile URL and a write to /etc/zshenv or /etc/zprofile were not recognised. They are now refused; downloads into ordinary folders such as ./downloads are still allowed.
