### Fixed
- On Windows, a path written with 8.3 short names for every part, including the profile folder of a user whose name has a space or an accent (`C:\Users\JOSPRE~1\AWS~1\CREDEN~1` for `C:\Users\José Pérez-Núñez\.aws\credentials`, or `CLAUDE~1\SETTIN~1.JSO` for the agent settings), is now resolved to its long name before the protected-path rules read it, so it is blocked like the plain name. Before, only short names that are a prefix of the long name were recognized.
