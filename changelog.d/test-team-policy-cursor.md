### Changed
- Tests and docs now show that the Team policy applies to Cursor through `zn run` and the `secrets` MCP server: a blocked secret, a narrowed host, a warning, expiry and an invalid policy behave as for Codex. Separately, Cursor blocks shell commands and MCP calls that carry a secret marker, whatever the policy says. The docs explain how the policy reaches each agent and that the `secrets` MCP server is added to Cursor by hand (the install prints the line).
