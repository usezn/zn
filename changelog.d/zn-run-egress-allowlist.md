### Added
- `zn run --egress-allow HOST[:PORT],...` (opt-in, off by default) limits the hosts a command reaches over HTTP(S): a local proxy on 127.0.0.1 is set for the command through `HTTP_PROXY`, `HTTPS_PROXY` and `ALL_PROXY`, and requests to other hosts get 403. It covers programs that honour the proxy variables, not programs that ignore them, raw sockets or DNS. See "Egress allowlist for `zn run`" in the secrets guide.
