### Security
- The pre-tool check now also sees a curl configuration file (or a folder curl reads its default configuration from) named by a command through a folder inside an option (`--target-directory=DIR`, `--directory=DIR`, `cp -tDIR`, `tar -CDIR`) or through `$PWD`, and refuses the command, as it already did for a separate argument. A folder written with `$OLDPWD` or with another expansion of `PWD` (`${PWD:-.}`, `${PWD%/}`) is refused, since zn cannot follow it.
