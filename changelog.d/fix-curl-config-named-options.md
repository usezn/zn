### Security
- The pre-tool check now also sees a curl configuration file (or a folder curl reads its default configuration from) named by a command through a folder inside an option (`--target-directory=DIR`, `--directory=DIR`, `cp -tDIR`, `tar -CDIR`, `unzip -dDIR`, `7z x -oDIR`) or through `$PWD`, and refuses the command, as it already did for a separate argument. A folder written with `$OLDPWD` is refused, since zn cannot follow it. A variable zn does not resolve (`${HOME}${zz}`, `$PWD$zz`, `${1:-.}`, `${HOME:-~}`, `${!name}`) may be empty or any folder: it counts when it is the destination folder of a program that writes into a folder, or when the text after it ends a protected path or a folder that holds one. A plain literal default (`${DIR:-.}`) is read as that literal, so everyday install and build lines stay allowed.
