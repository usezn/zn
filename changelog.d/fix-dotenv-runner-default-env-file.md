### Security
- The shell hook refuses `dotenvx run`, `dotenvx get` and the other `dotenvx` steps that load the default file, and `dotenv` (dotenv-cli) run without `-e`, when the project `.env` holds a plain-text secret or an encrypted value, the same as when the command names `.env` with `-f`. Before, only the form that typed the file name was checked, so `dotenvx run -- printenv` printed the values. With `--convention` (dotenvx) or `-c` (dotenv-cli) the `.env.local`, `.env.development`, `.env.production` and `.env.test` files are checked too. A project whose `.env` has no secret, or has none, is not affected.
