### Security
- The `.env` guard no longer treats the file named after `-f` or `--env-file` as a read for every `dotenvx` command: only `dotenvx run` reads it, handing the values to the program it starts. `dotenvx get`, which prints decrypted values where the agent can read them, and `dotenvx set`, `encrypt`, `decrypt` and the other subcommands, which rewrite the file, are now refused, as for any other command that names a `.env` file.
