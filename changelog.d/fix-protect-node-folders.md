### Security
- The folders where the zn hooks and plugins look for `node` and `zn` are now protected from the agent: `~/.local/bin`, `~/bin`, `/usr/local/bin` (when you own it), the Node.js version manager folders (`~/.nvm`, `~/.volta`, `~/.fnm`, `~/.asdf/shims`) and their Windows equivalents. An agent could replace a `node` or `zn` there, and the hooks would then run it. File tools and shell commands can no longer write, replace, move, delete or link a `node` or `zn` in those folders; reading them, other files in the same bin folders and project files such as `bin/node` still work.
