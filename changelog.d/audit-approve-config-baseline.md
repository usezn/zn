### Added
- `zn audit --approve` records the executable configuration of a project (MCP servers of Claude Code, Cursor, VS Code, Gemini, Amazon Q, OpenCode and Codex, hooks with their matchers, permissions, `disableAllHooks`, helper commands, endpoint, proxy and loader environment overrides, install scripts, dev container commands, folder-open tasks) and later audits report a changed, added or removed entry as ZNA022, by name only. A config file that is a link inside the project is followed, and one that can no longer be read counts as a change. An agent cannot run the approval: zn blocks `audit --approve`. Without a recorded baseline nothing changes.
