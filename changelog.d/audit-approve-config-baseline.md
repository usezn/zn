### Added
- `zn audit --approve` records the executable configuration of a project (MCP servers of Claude Code, Cursor, VS Code, Gemini, Amazon Q, OpenCode and Codex, hooks with their matchers, permissions, `disableAllHooks`, helper commands, endpoint, proxy, loader and shell-prefix environment overrides, install scripts, dev container commands, folder-open tasks) and later audits report a changed, added or removed entry as ZNA023, by name only. A config file that is a link is followed inside the project and hashed by content outside it, and one that can no longer be read counts as a change. An agent cannot run the approval: zn blocks `audit --approve` also when it is quoted, split, escaped or fed through `xargs`, and the same reading now covers the other commands only you may run. Without a recorded baseline nothing changes.
