### Security
- The gateway now rejects JSON-RPC frames that are arrays or plain values, so a tool call hidden in an array can no longer reach the MCP server unchecked. JSON-RPC batches were never supported on the client side; they now get a parse error instead of being forwarded.
- The management API now closes connections that stall while sending headers (after 10 seconds) or a request body (30 seconds without new data), and serves at most 256 connections at once, so half-open connections can no longer use up the server's file descriptors.
- The management API now answers 400 Bad Request to a request that sends both `Content-Length` and `Transfer-Encoding` (or `Transfer-Encoding` on HTTP/1.0), as RFC 9112 requires, so a proxy in front can no longer be made to read a request differently from the gateway.
