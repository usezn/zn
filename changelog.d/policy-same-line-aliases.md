### Security
- The hook policy now reads aliases that a command line defines and then calls. A shell alias (`alias x='...'; x`) or a git alias (`git config alias.y '!...' && git y`, `git -c alias.y='!...' y`) is checked as if its body had been typed in its place, so a body that deletes the home folder, writes to a disk device, runs a zn admin command or touches a protected file is blocked. A line that calls an alias whose body starts with a variable or a command substitution is blocked too, because the body cannot be read before it runs. Harmless aliases such as `alias ll='ls -la'; ll` and `git config alias.st status && git st` are still allowed.
