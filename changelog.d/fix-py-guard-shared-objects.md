### Fixed
- Python: a tool result that held the same object many times, or a logger, could be blocked with rule `size:items`, because the value budget counted an object again each time it was reached. An object read in full is now counted once. A logger is read without its links to the other loggers of the process, and its handlers, filters and any attribute a subclass adds are now checked (1.14.0 skipped logging objects); the logging manager is skipped. The budget counts attribute names and values, about 50,000 attributes.
