### Security
- The hook no longer lets an oversized tool output through unchecked. When a post-tool event was larger than 32 MiB and its event name came later than the first 64 KiB, the hook could not tell what kind of event it was and answered with exit code 2, which does not stop Claude Code or Codex from showing the original output to the model. The hook now finds the event name in all the text it has read, whatever the order of the keys, and withholds the output of a post-tool event that is too large to check. An event whose name is not in the text that was read is treated the same way.
- The Claude Code, Codex and Cursor plugin launcher now stops reading an event from stdin at 32 MiB instead of reading and parsing all of it, and answers an oversized event the same way (blocking events are blocked with a reason, tool output is withheld).
