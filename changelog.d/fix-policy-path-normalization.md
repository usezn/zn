### Security
- The hooks now read a path the way the file system does before checking zn's state folder, registry token files and agent configuration: separators written as backslashes, `..` segments and, on Windows, trailing dots and spaces in a folder or file name no longer change the result. More ways of writing your home folder are recognized (the braced PowerShell variable, `%HOME%` and `~` followed by your user name). Gemini CLI and Antigravity configuration folders are protected like the other agents' folders, and the shared `.agents` folder itself can no longer be removed or moved by an agent (what other tools keep inside it is unchanged).
