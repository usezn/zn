### Fixed
- Copilot and VS Code tasks started with create_and_run_task are now checked in every platform override (linux, osx, windows) as well as the base task, and the strictest verdict wins. A task that sets a custom options.shell is judged like a shell task, as it is launched (shell, flags, command): only known shells (bash, sh, zsh, dash, fish, pwsh, powershell, cmd, nu) with their own flags are accepted, so the command can no longer hide in the shell settings.
- A task's options.cwd (base or override) is resolved and the line is judged in that folder; a folder outside the workspace, an unknown ${...} variable or a value that is not text is blocked. options.env is checked against the dangerous-environment list, and unknown keys under options are blocked. Overrides, options or shell settings in a shape zn cannot read are blocked instead of passing.
