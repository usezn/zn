### Security
- OpenCode: zn now treats an MCP server as its own `secrets` server (the one whose calls may carry secret markers) only when it is defined in your own OpenCode configuration and runs the `bin/cli.js` of the zn-gate installation that is running the hook. Before, any server whose command ended in `/zn-gate/bin/cli.js` outside the project was accepted, including one a project's `opencode.json` or `OPENCODE_CONFIG_CONTENT` defined, a copied package named `zn-gate`, or a link into the project. Such a server never received secret values, only the names of markers, and is now checked like any other MCP server. The install hint for `--project` now points to your own `opencode.json`.
