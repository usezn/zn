### Security
- GitHub Copilot in VS Code: tool calls zn did not recognize no longer pass unchecked. Any tool that names a file or folder gets the same read and write checks as the built-in tools, a file written with `apply_patch` is checked like any other write (including `.github/hooks` and `.claude/settings.json`), and a command sent as `task.command` with its `task.args` (for example `create_and_run_task`) is checked as a shell command, with the line built the way VS Code builds it for a shell task, argument by argument (an argument with a space outside quotes is wrapped in single quotes, any other argument, including one with a tab or newline, is left as typed, so the command after a newline is seen) and also read other ways (bare values, every argument quoted), so `bash -c 'rm -rf ~'`, `echo x&&rm -rf ~` and a newline hidden in an argument are judged as they would run. A command or argument zn cannot read is blocked instead of being skipped.
