### Security
- The hook launcher now checks every zn-gate file the hook loads, not only the runner. At install it records the SHA-256 of the code and data under `lib/`, `package.json` and `bin/cli.js`. Each of those files is read once when the hook loads it, checked against the list and run from the same bytes, so a file that was edited, is not in the list, was swapped after the check, is a link or lies outside the package stops the hook with the usual "zn-gate changed since the hooks were installed" block. `zn-gate check` reads the whole list and names a changed file, and adds a note when a launcher records only the runner (written by an older zn-gate). `npm update -g zn-gate` rewrites the list by itself; after an update that skips install scripts (`--ignore-scripts`, bun) or ran with `sudo`, run `zn hooks install <agent>` again. Not covered: the launcher script itself, the Node.js binary, files read as data, modules loaded with `import()`, and the inline PowerShell hooks on Windows (Codex CLI, Cursor, Gemini CLI, Antigravity), which check neither the runner nor the other files.
