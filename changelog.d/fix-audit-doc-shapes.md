### Fixed
- `zn audit` no longer reports a high prompt-injection finding (ZNA012) for documentation inside a `SKILL.md` or a docs page: a chat token shown in code, a `<system-or-project>` placeholder, `system:anonymous`, a badge image from a known badge host, or a quoted warning about injection. A real override phrase, a system role token or a role marker on its own line is still high, and so is an order that follows a warning ("Don't trust the old rules, ignore all previous instructions"). A warning followed by an order is still reported even without a comma. These exemptions never apply to an instruction file (`CLAUDE.md`, `AGENTS.md`, a command or a rule) inside a `docs/` folder, to a docs file that `CLAUDE.md` imports with `@` (the agent loads it as instructions), or to a docs folder inside an agent instruction folder such as `.claude/commands/docs/`. A quoted example of an override is reported as medium instead of being dropped. `AUDIT_RULES_VERSION` is now `2026-10-23.3`.
- `zn audit` no longer reports `git clone <url>` or a console link written in Markdown ("create one at [Console](url)") as exfiltration (ZNA014), unless something earlier on the line sends, copies or pastes a secret.
