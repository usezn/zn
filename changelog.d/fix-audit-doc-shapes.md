### Fixed
- `zn audit` no longer reports a high prompt-injection finding (ZNA012) for documentation inside a `SKILL.md` or a docs page: a chat token shown in code, a `<system-or-project>` placeholder, `system:anonymous`, a badge image from a known badge host, or a quoted warning about injection. A real override phrase, a system role token or a role marker on its own line is still high, and so is an order that follows a warning ("Don't trust the old rules, ignore all previous instructions"). A docs folder inside an agent instruction folder such as `.claude/commands/docs/` gets no exemption, and a quoted example of an override is reported as medium instead of being dropped. `AUDIT_RULES_VERSION` is now `2026-10-22.4`.
- `zn audit` no longer reports setup steps as exfiltration (ZNA014): `git clone <url>`, `cp .env.example .env` and "create a key at [Console](url)". Sending a secret to a URL is still reported.
