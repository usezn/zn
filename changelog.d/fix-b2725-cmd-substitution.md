### Fixed
- The destructive-command check now reads the body of a `$( )` command substitution inside double quotes as a command. `echo "$(rm -rf ~)"` was allowed because the delete was only an argument of `echo`, but Bash runs it. `checkCommand()` and `check_command()` give the same answers; `$(( ))` arithmetic, text in single quotes and an escaped `\$(` are still not read as commands. A substitution body whose end the scanner cannot determine (a case pattern, a comment, a here-document, a `${ }` expansion or a backtick span) is read to the last closing parenthesis of the string, and `$'...'` is read as ANSI-C quoting. The rules version is `2026-10-31.5`.
