### Fixed
- `zn-gate init --revert` now takes the zn-gate wrapper off each wrapped MCP server in place instead of copying back the newest backup. After two `init --wrap-mcp` runs it used to say "reverted" while some servers stayed wrapped, and any change made to the file after wrapping (such as a server you added) was lost. Now every wrapped server in the Claude Desktop, Claude Code, Cursor, Antigravity, Codex, OpenCode and Hermes configs gets its original command back, other edits stay, older backups are kept, and the command says how many servers it reverted or that nothing was wrapped. A wrapper zn-gate did not write is left alone and named, and the command exits with an error. `zn-gate uninstall` uses the same un-wrapping.
