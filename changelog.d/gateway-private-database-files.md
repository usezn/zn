### Security
- The Rust gateway built from `src/` (not part of the npm, PyPI or plugin releases) now creates its audit database and the vector memory files so that only your user can read them (mode 0600, and 0700 for the `data` folders on Unix; an owner-only access list for a new database file on Windows). Before, SQLite used the default permissions, usually readable by every local account, and the `-wal` and `-shm` files copied them. Existing files that other accounts can read are restricted at start with a warning, and with `ZN_ENV=production` a file that cannot be restricted is refused.
