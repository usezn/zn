### Security
- The hook of a project install (`zn hooks install <agent> --project`, the `sh -c` guard written in the shared project files) no longer starts a `zn` or `node` found in an absolute `PATH` entry whose real path is in the project: the folder the hook runs in, the git work tree around it, the project folder the agent names (`CLAUDE_PROJECT_DIR`, `CURSOR_PROJECT_DIR`) or a `node_modules` folder, also through a link. The hook then blocks and says how to install zn-gate, as when `zn` is missing. This is the rule the zn-gate plugins already follow. Antigravity's project guard is not changed yet. Run `zn hooks install <agent> --project` again to write the new guard; `zn-gate check` reports the older one.
