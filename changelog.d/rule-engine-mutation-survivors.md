### Security
- The command check now refuses a shell command nested more than three levels deep (for example sh -c inside sh -c several times, or a backtick substitution inside the third level) instead of letting it through unchecked, and it blocks a write to a shell startup file such as .bashrc after a cd whose target cannot be resolved (for example a variable with several possible values). The Python package gets the same fixes.
- The command check now also reads the command that find runs with -exec, -execdir, -ok and -okdir (a shell started that way counts toward the nesting limit), reads a command substitution whose quotes re-open a double-quoted shell string (bash -c "echo $(bash -c "...")") at its real nesting level, and blocks a download written to the ssh authorized_keys file (the block message now names it), including after a cd whose target cannot be resolved. Deeply nested quoted substitutions are refused quickly instead of being rewritten without end. The Python package gets the same fixes.
