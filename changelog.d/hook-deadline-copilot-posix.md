### Fixed
- Copilot CLI hooks now have a deadline that starts before Node.js does on macOS and Linux and in project installs on every system, not only in a Windows user install. Copilot lets a call through when a hook times out, so if the hook was stuck before zn could answer (a slow disk, an antivirus scan, a busy machine), the call ran unchecked. Now a user install on macOS and Linux runs the hook through zn's launcher script, which stops it 2 seconds before Copilot's timeout and denies the call itself, and a project install carries the same deadline inside its hook command. Run `zn hooks install copilot` (and `zn hooks install copilot --project` in each project) again to get it; `zn-gate check` reports a project hook that is still the older one.
