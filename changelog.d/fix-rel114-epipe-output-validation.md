### Fixed
- When a hook could not write its answer to the agent (for example the agent closed the pipe), zn-gate exited with status 0 and the launchers accepted it, so a block could be lost. A failed write now fails the hook, and the launchers only accept a hook that confirms it wrote its whole answer; otherwise they block the action (or warn, for events that cannot be blocked) and tell you how to fix it. The launchers' private files now get random names. They are removed after every call, also when the hook runs with an empty PATH.
