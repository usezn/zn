### Security
- The hook policy now refuses `curl` and `wget` commands that hide the program behind a variable (`c=curl; $c -K cfg`), PowerShell `& $c` or `& ("cu"+"rl.exe")`, `Start-Process curl.exe -ArgumentList ...`, a cmd caret (`c^url`) or a command substitution inside an argument, in the same cases where it already refuses the plain `curl` command: a configuration file given with `-K`, or a protected file sent with `-T` or `@file`. A command word the policy cannot resolve that is followed by curl or wget file options is treated as curl or wget. `wget --config`, `wget -e` and `--execute` commands that are not plain download settings, and `WGETRC` are now refused like curl `-K` and `CURL_HOME`, and `busybox wget -O` to an agent instruction file now gets the same notice as `wget -O`.
