### Added
- Experimental: `zn hooks install copilot [--project]` adds hooks for GitHub Copilot CLI (`~/.copilot/hooks/zn-gate.json` for your user, `.github/hooks/zn-gate.json` in a project). It blocks the agent from reading or writing secret files by path and from running shell commands that handle secrets, replaces secret values in the results of read-type and shell tools, and protects Copilot's hook and settings files from edits by the agent. Copilot cannot block a typed prompt from a command hook, lets a call through when a hook times out, and also loads machine policy hooks of its own. `zn-gate check` reports the Copilot hook, including a `disableAllHooks` setting that turns it off.
