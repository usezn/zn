### Security
- `zn-gate init --revert` now restores only the newest backup next to the config, named `<config>.bak.<number>`. A repository's project-level agent config (`.agents/mcp_config.json`) is only touched when it is a plain file inside the project (no symlinks, no extra hard links), and any backup that is a symlink or sits in another directory is skipped with a message, so a repository can no longer redirect a restore onto your own MCP config or copy a private file into the project. Configs and backups are now written through a temporary file and a rename. Symlinked agent configs in your home folder (for example managed by stow, yadm or chezmoi) keep working: `init` and `init --revert` update the real file they point to, as long as it is inside your home folder.
