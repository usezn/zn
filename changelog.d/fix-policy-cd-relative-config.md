### Security
- Hook policy: a relative name after a `cd` is now judged in the folder the `cd` reached. `cd ~/.gemini && echo {} > settings.json` (and the same for the Antigravity, Gemini, Claude Code, Codex, Cursor, OpenCode and Copilot settings and hook files) was allowed because the file name alone looked harmless; it is now refused, and so is a read of a secret file such as `cd ~/.aws && cat credentials`. When the `cd` goes somewhere zn cannot follow (`cd "$(...)"`, `cd $DIR`), a write to a relative name that would be agent configuration in an agent folder the command names is refused. Reading these files and writing files with the same names in other folders is still allowed.
