### Changed
- The removal guides now give one order, the one `zn-gate uninstall` uses: put back wrapped MCP servers first (`init --revert`), then remove the hooks and the Claude Code plugin, then the vault if you want it deleted, and the program last (`npm uninstall -g zn-gate`, then `pip uninstall zn-gate`). A saved copy put back after the hooks are removed could bring back zn's `secrets` server, and removing the program first leaves your agent pointing at a missing command. The README files, the first-5-minutes guide, the FAQ and the removal guide give the same order.
