### Changed
- The removal guides now give one order. `zn-gate uninstall` follows it for the wrapped MCP servers, the hooks and the Claude Code plugin: it puts back wrapped MCP servers first (`init --revert`), then removes the hooks and the plugin, and asks separately before it deletes the vault. The program is removed last, by hand (`npm uninstall -g zn-gate`, then `pip uninstall zn-gate`). A saved copy put back after the hooks are removed could bring back zn's `secrets` server, and removing the program first leaves your agent pointing at a missing command. The README files, the first-5-minutes guide, the FAQ and the removal guide give the same order.
