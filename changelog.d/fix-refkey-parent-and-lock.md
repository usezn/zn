### Security
- The folder that holds the audit reference key (`ref.key`) is now created owner-only (0700). If it already exists and is a symbolic link or belongs to another user, the gateway refuses to start with a clear error; if it is yours but group or others can write to it, zn tightens it to 0700 and logs a warning. When several processes find a truncated key at the same time, one replaces it under a lock file and the others use the key it wrote, so they never end up with different keys.
