### Fixed
- `zn audit` no longer reports text that discusses `curl | sh` as a risk (a checklist of risky patterns, a warning table, a rule that lists what to flag) as an instruction to download and run code. An install instruction is still reported when it sits under a heading such as "Don't forget" or "Vulnerability scanner", inside a code block, after words such as "detect" or "look for", after "without verification", behind a "Critical:" label or in a table row with an errors column. Audit rules version 2026-10-23.4.
