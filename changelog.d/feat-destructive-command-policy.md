### Added
- Optional, off by default: a check that refuses a few destructive shell commands. Turn it on for the agent hooks with `{"hooks": {"blockDestructiveCommands": true}}` in `~/.zn/config.json` (or `ZN_BLOCK_DESTRUCTIVE=1`, which can only turn it on). It blocks a recursive delete of the home folder or the filesystem root, a download piped to a shell (`curl ... | sh`, `iwr ... | iex`), writes to a disk device, `chmod -R` or `chown -R` on the root or a system folder, a fork bomb, and a download written into a shell startup file. It reads command text only and is not a sandbox. SDK users get `checkCommand` (Node.js, `zn-gate/lib/client`) and `check_command` (Python), which always apply it. See `docs/destructive-commands.md`. `POLICY_RULES_VERSION` is `2026-10-19.42`.
