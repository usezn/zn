### Changed
- The first hook call of the ZCode plugin on Windows is about three times faster. The plugin no longer starts Windows PowerShell for every hook: a small `scripts/zn-hook.cmd` starts Node.js directly from its usual install folder (`%ProgramFiles%\nodejs\node.exe`) and falls back to the previous PowerShell command when Node.js is somewhere else, so the answer is the same. The launcher also reads the files it verifies (the same byte-for-byte check, nothing skipped or cached) 16 at a time instead of one after another. Measured on a fresh Windows Server 2022 machine (2 vCPU) with Defender on, the first hook call of the machine takes 0.7 s instead of 2.0 s (median of two runs); a later call takes 0.3 s instead of 0.9 s. `zn-gate check` accepts both the new Windows hook and the PowerShell one that earlier plugin versions ship.
