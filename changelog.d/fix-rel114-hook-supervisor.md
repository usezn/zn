### Security
- A hook whose input never ends, or whose check never finishes, now blocks the call before the agent's own hook timeout instead of leaving the agent with no answer (which lets the call run). A timer starts as the hook starts, before it reads its input, for every agent; the launcher scripts of Claude Code, Codex CLI, Cursor, Gemini CLI and Antigravity add a deadline that stops the whole hook. Gemini CLI and Copilot CLI, whose 15-second timeout lets a call through, are answered with a block at 11 seconds, and the vault client no longer waits past that deadline. A SIGTERM, SIGHUP or SIGINT during a tool-call check also answers with the block instead of exiting with no answer.
