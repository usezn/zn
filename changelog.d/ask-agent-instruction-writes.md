### Security
- The agent hooks now ask before an agent writes to the files where it keeps memory and standing instructions: `MEMORY.md`, `SOUL.md`, `AGENTS.md`, `CLAUDE.md`, `CLAUDE.local.md`, `GEMINI.md`, `.cursorrules`, `.windsurfrules`, `.cursor/rules/*`, `.github/copilot-instructions.md` and the Claude Code memory folders. Agents read these files in later sessions, so an instruction written there (for example by a skill or a tool result) would keep working after the skill is removed. File tools, shell redirections, `tee`, `cp`, `mv` (including a copy into a directory), `curl -o` / `wget -O` and in-place edits are checked, and only the command word counts (`grep -n patch CLAUDE.md` is a read); reading these files is never blocked. In strict mode (`{"hooks": {"strict": true}}` or `ZN_STRICT=1`) the write is refused instead. To turn the question off, set `{"hooks": {"agentInstructionWrites": "off"}}` in `~/.zn/config.json`. Agents that cannot ask (Codex CLI, Gemini CLI, OpenCode, and Cursor's file tools) keep their own approval rules. See `docs/compat.md`. `POLICY_RULES_VERSION` is `2026-10-23.5`.
