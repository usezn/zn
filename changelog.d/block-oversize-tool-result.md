### Security
- A tool result larger than 4 MB is now blocked by default (rule `size:truncated`) in the Node.js and Python packages. Only its first 4 MB and its last window were scanned, so an injection in the middle of a large result was allowed with `truncated` set. Set `ZN_ALLOW_TRUNCATED=1`, or pass `allowTruncated: true` (Node.js) or `allow_truncated=True` (`check_tool_result`, `sanitize_tool_result`), to let such a result through marked `truncated`. `blockTruncated`, `block_truncated` and `ZN_BLOCK_TRUNCATED=1` still force the block. The MCP shield already blocked results over 32 MB and is unchanged.
