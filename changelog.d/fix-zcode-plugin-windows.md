### Security
- The ZCode plugin no longer lets tool calls run unchecked on Windows. Its hooks started `/bin/sh` by its full path, which Windows does not have, so the hook never ran and ZCode ran every tool call without zn (`zn-gate check` reported it as not protected, but nothing stopped the calls). Every plugin event now also has a hook that starts the Windows PowerShell by its full path and runs a PowerShell version of the launcher (`scripts/zn-hook.ps1`), with the same checks of the bundled zn-gate files, the same Node.js search outside the project and the same 28-second deadline. On each system only the matching hook can start. `zn-gate check` runs the Windows hook there. Install the plugin again in ZCode (Settings, Plugins) once a release with this fix is published.
