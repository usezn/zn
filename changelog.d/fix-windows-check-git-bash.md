### Fixed
- Windows: `zn-gate check` and `check --json` reported Claude Code as protected (exit code 0) when zn's own hooks were installed with `zn hooks install claude-code` but Git Bash was missing, while `check --hooks` said the hooks could not run. Claude Code runs zn's hook launcher with Git Bash, so without it the hooks never start. All three now say not protected (exit code 1), with Git for Windows as the fix, and `zn hooks install claude-code` warns when it finds no Git Bash. The fix for the plugin without Git Bash no longer suggests zn's own hooks, which need Git Bash too.
- Docs: Windows needs Git for Windows for both Claude Code routes; recent npm versions skip the launcher refresh unless install scripts are allowed (`npm install -g --allow-scripts=zn-gate zn-gate`, or `zn hooks install <agent>` after the update); the list of files that `hooks install` writes now covers every agent, and the `.zn` folder table lists `cache/compile` and `state`.
