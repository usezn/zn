### Security
- Secret redaction (npm and Python packages): a key or token inside a base64 string (plain or wrapped over several lines), inside JSON `\uXXXX` escapes, or assembled by a shell variable expansion (`A=AKIA; echo "$A"IOSFODNN7EXAMPLE`) is now redacted. Before, only the plain text was checked, so these forms were left in the text. A base64 string is only replaced when it decodes to mostly printable text that holds a secret, so images, hashes and ordinary encoded text are left alone. Expansions are resolved only for simple `NAME=value` assignments earlier in the same text; other shell constructs (command substitution, other transformations) are not evaluated.
