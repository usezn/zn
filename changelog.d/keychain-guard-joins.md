### Security
- The key-protection rule now also recognises zn-gate's key module when its name is built in the command (joined with `+`, `.concat()`, `path.join` or an array join, across lines or with escaped quotes, also after the shell decodes `\x27`) or sits in a Bun or Deno cache folder. Names written with URL encoding or look-alike letters are not matched because Node does not resolve them either, and Windows 8.3 short names remain a known limit of this barrier.
