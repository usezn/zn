### Security
- The Claude Code plugin repository builder now refuses the common ways for bundled code to run code from a string or to reach Node's module loader: `eval`, the `Function` constructor (also through a `.constructor` member, `module.constructor`, or taken out of an object by destructuring), `process.binding`, the `vm` and `worker_threads` built-ins, and a `require()` with a name that is not a plain quoted string. Computed property names and `Reflect` are documented limits of this check.
