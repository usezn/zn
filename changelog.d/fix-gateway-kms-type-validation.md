### Security
- Experimental Rust gateway (not distributed): the gateway no longer treats an unknown `kms.kms_type` (for example `AWS-KMS`, `aws_kms` or a typo) as the local vault. Only `local` and `aws` are accepted, ignoring surrounding whitespace and capitalisation; anything else, including an empty value, stops the gateway at start-up with a message that suggests the closest valid value. `kms_type = "aws"` without `kms.key_id` now also stops at start-up instead of quietly using the key from the config.
