### Security
- The destructive-command check now reads the code given to `python -c`, `node -e`, `perl -e` and `ruby -e` (also behind `sudo` or `env`). A one-liner that recursively deletes the home folder, the filesystem root or a system folder (`shutil.rmtree`, `fs.rmSync` with `recursive`, `remove_tree`, `FileUtils.rm_rf`, `unlink glob`) is blocked as `rm_root_home`. A download piped into `python`, `node`, `perl` or `ruby` that reads the program from the pipe (`curl ... | python3`, `| sudo python3 -`) is blocked as `pipe_to_shell`; `| python3 -m json.tool` and `| python3 script.py` stay allowed.
