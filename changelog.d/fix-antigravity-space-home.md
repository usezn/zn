### Fixed
- Antigravity: with a space in the home folder path, `zn hooks install antigravity` wrote a hook command that Antigravity could not start (it splits the command on spaces and has no quoting), yet reported success and `zn-gate check` said it worked. Install now refuses with a plain message and the way out (`ZN_HOOK_DIR=<folder with no spaces> zn hooks install antigravity`), and `zn-gate check` runs the same split and reports a hook that cannot start. `ZN_HOOK_DIR` is used only when its path has no link and the folder and every folder above it is owned by you or by root and has no write for group or others (no exception for the sticky bit, so `/tmp` is refused); otherwise install refuses before writing anything and says why, so nobody else can swap the launcher that runs on every tool call.
