### Security
- Windows: a protected file named with an 8.3 short name behind a namespace or device prefix (`\\?\`, `\\.\`, `\??\`, `//?/`) or an admin share of the same machine (`\\localhost\C$\`, `\\?\UNC\localhost\C$\`, or the machine's own name, domain name or IPv4 address) is now refused by shell commands such as `type` and by file reads. The prefix is replaced by the drive before the path is checked. A short name behind a prefix that zn cannot map to a drive, such as `\\?\Volume{...}\`, `\\?\GLOBALROOT\Device\...` or an admin share on another host name, is refused because zn cannot check it.
