### Fixed
- The gateway scrubber now redacts the same personal data as the Node scrubber: IBANs (country length and checksum), Spanish DNI and NIE numbers (check letter), and a person's name, postal address or username when it follows an explicit key such as `X-User-Name:`, `X-Address:`, `X-Username:`, `name=`, `address=` or `username=` in a header, query string or form body. Only the value is replaced, with `[IBAN_REDACTED]`, `[DNI_REDACTED]`, `[NIE_REDACTED]`, `[PERSON_NAME_REDACTED]`, `[POSTAL_ADDRESS_REDACTED]` or `[USERNAME_REDACTED]`. A name, address or username with no key next to it is never touched.
- The gateway scrubber can also redact public IPv4 addresses (private, loopback and documentation ranges are always left alone). Like in the Node scrubber, this is off by default, and the personal-data types can be switched on or off one by one.
