### Security
- A program that reads every file of a folder it is given can no longer be pointed at a credential folder such as `~/.aws`, `~/.ssh`, `~/.kube`, `~/.config/gh`, `~/.docker` or `~/.gnupg`: `tar c`, `zip -r`, `7z a`, `rsync`, `cp -r`, `scp -r`, `grep -r`, `rg`, `ag` and `find ... -exec cat` are refused, also after `tar -C DIR` or a `cd DIR` followed by `.`. The same programs are refused on a parent folder that contains one (`~`, `~/.config`) when they read it recursively. Listing a folder (`ls`, `du`) and the usual project commands (`tar czf out.tgz src`, `zip -r app.zip dist`, `grep -r TODO .`) stay allowed.
