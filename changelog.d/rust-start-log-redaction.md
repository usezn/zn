### Fixed
- The experimental gateway (`zn start`) no longer writes log lines to stdout, which carries the JSON-RPC replies; logs and the first-run banner go to stderr. Log lines, tool names, audit rows and event metadata now pass through one redactor that also masks AWS access key ids and secret access keys (also the `SecretAccessKey` field of temporary credentials), Google API keys, GitHub and GitLab tokens, Stripe keys and webhook secrets, OpenAI and Anthropic keys, Slack tokens and Slack and Discord webhook URLs, private key blocks (including PGP) and IBANs in upper or lower case. Forwarded calls are unchanged.
