### Security
- The shell hook now works out `printf` with several arguments, a reused format and octal or hex escapes inside a command substitution, and `basename` and `dirname` of a written-out path, so a `.env` file, an SSH private key or the cloud credentials file can no longer be read or written under a name built that way (for example `cat $(printf %s%s .e nv)` or `cat $(printf '\056env')`). A command substitution that filters or lists text close to such a name and is used as a file name (for example `cat $(ls -a | grep env)`) is also refused, because its output cannot be checked. Other substitutions, such as `$(git rev-parse --show-toplevel)`, `$(mktemp)` and `$(pwd)`, are unchanged.
