### Security
- The shell hook now works out `printf` with several arguments, a reused format and octal, hex or unicode escapes inside a command substitution (and `printf -v NAME ...` assignments), plus `basename` and `dirname` of a written-out path, so a `.env` file, an SSH private key or the cloud credentials file can no longer be read or written under a name built that way (for example `cat $(printf %s%s .e nv)` or `cat $(printf '\056env')`). A command substitution whose output cannot be checked, because it pipes text through a filter (`rev`, `base64 -d`, `tr`, `sed`, `cut`, `xxd` and similar) or runs inline code, or because it lists files and names text close to such a file, is refused when it is used as a file name. Other substitutions, such as `$(git rev-parse --show-toplevel)`, `$(mktemp)`, `$(pwd)` and `$(ls -t | head -1)`, are unchanged.
