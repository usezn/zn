### Security
- Writes to an agent instruction file (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.cursorrules`, `.github/copilot-instructions.md`, `.cursor/rules/*`, memory files) made inside a `python -c` or `node -e` one-liner now get the same question as any other write to those files. zn reads a quoted file name given to `open(..., "w"/"a"/"x")`, `Path(...).write_text`, `write_bytes`, `fs.writeFile`, `writeFileSync`, `appendFile`, `appendFileSync` or `createWriteStream`, with `./`, `../` and `~/` prefixes; reading the file stays allowed. `POLICY_RULES_VERSION` is `2026-10-25.2`.
