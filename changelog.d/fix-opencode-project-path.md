### Security
- OpenCode: the plugin of a project install (`zn hooks install opencode --project`) no longer starts a `zn` from the project. It keeps only the `PATH` entries whose real folder is outside the project (the folder OpenCode opened, the folder it runs in and the git work tree around them) and outside `node_modules` folders, looks `zn` up there itself, skips a `zn` that links into the project, and starts it by its full path; the `node` that `zn` starts gets the same `PATH`. Before, an absolute `PATH` entry into the project (its `bin` folder, `node_modules/.bin`, a folder added by direnv) could make the plugin start a program of the project. Run `zn hooks install opencode --project` again to write the new plugin.
