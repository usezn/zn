### Fixed
- The scrubber now redacts more provider token formats, the same way in the Node.js and Python packages: Cloudflare API tokens (`cfut_`), GitLab tokens with the `gloas-`, `glimt-`, `glagent-`, `glwt-` and `glffct-` prefixes, Sentry organization tokens (`sntrys_`) and the single-use Sentry setup and handoff codes (`sntryc_`, `sntryh_`), New Relic license keys (40 hexadecimal characters after `NEW_RELIC_LICENSE_KEY`), and npm access tokens in the older hexadecimal form after `_authToken` in an `.npmrc` line. A bare hexadecimal value without its key name is left alone.
