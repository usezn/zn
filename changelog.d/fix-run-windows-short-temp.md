### Security
- On Windows, `zn run` now refuses an allowed command that resolves to a file in the temp folder whatever name the PATH entry uses for that folder: its long name, its short 8.3 name (for example `C:\Users\LONGNA~1\AppData\Local\Temp`), a `subst` or mapped drive, or a `\\?\` path. Before, when the temp folder and the PATH entry used different names for it, such a file was not seen as inside the temp folder and could run with the secret. The check for files inside the project compares the same forms.
