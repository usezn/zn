### Security
- The identity-request rules (`pi:identity_request` and `pi:identity_request_multi`) now catch more variants of text in a tool result that tells the agent to put its user's details in a request: "the user email" without the apostrophe, "their email" and "your email", an instruction that wraps onto a second line, and an instruction to run `whoami` or `git config user.email` and put the result in a header, URL parameter, cookie, form field or request. Sentences that tell you not to send the details, a contributing note that says to set `git config user.email`, and a script that only prints `whoami` are still not flagged. As before the rules are advisories by default and block in strict mode.
