### Changed
- One exit-code table for every command of the npm (`npx zn-gate`) and Python (`pip install zn-gate`) command lines: `0` nothing flagged, `1` flagged, `2` wrong usage, `3` scan coverage incomplete. Codes that change, which matters for scripts and CI: `analyze` of a blocked prompt exits `1` (was `2`); `analyze` with no text exits `2` (npm, was `1`); an unknown command exits `2` (was `1`); `scan` of a path that does not exist exits `2` (was `1`, the same as "secret found"). Agent hooks (`zn hook <agent>`) still exit `2` to block, as the agents expect.
- `zn-gate test` (Python) on text that holds a secret now starts with `SECRET FOUND` instead of `ALLOW`, because it exits `1`. The verdict line says `ALLOW (no prompt injection found)` and the JSON `verdict` is still `allow`.
