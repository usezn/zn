### Changed
- `zn audit --approve` now also records OpenCode plugin code (`.opencode/plugin/*.js`, `.opencode/plugins/*.js`) and the Amazon Q agent and rule files (`.amazonq/cli-agents/*.json`, `.amazonq/agents/*.json`, `.amazonq/rules/**/*.md`, `.amazonq/default.mcp.json`), each by the hash of its content, so a later audit reports one of them that changed, was added or was removed as ZNA023, by file name only. Links, the size cap and unreadable files follow the same rules as the other recorded files; a folder that exists but cannot be listed is recorded as unreadable, and past 500 files in one folder the rest is recorded together by name, size and time, so no file is left out; `.amazonq/mcp.json` is unchanged. Projects approved before this release see these files as added the first time, until `zn audit --approve` is run again.
