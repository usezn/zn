### Security
- The shell policy now reads environment variables that make git run a program as code, the way it reads an alias: GIT_PAGER, GIT_EDITOR, GIT_SEQUENCE_EDITOR, GIT_SSH_COMMAND, GIT_SSH, GIT_ASKPASS, GIT_EXTERNAL_DIFF, GIT_PROXY_COMMAND, PAGER, EDITOR and VISUAL, whether set before a command, after env, or exported earlier in the line. GIT_CONFIG_COUNT with GIT_CONFIG_KEY_n and GIT_CONFIG_VALUE_n, and GIT_CONFIG_PARAMETERS, are checked the same way, and keys that load configuration or hooks (core.fsmonitor, core.hooksPath, include.path, init.templateDir) are refused unless they are plain switches. A key or value that is not a literal is refused. The agent-level environment check lists the same variables. Quiet uses such as GIT_PAGER=cat or GIT_EDITOR=true are still allowed.
