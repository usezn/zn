### Security
- ZCode: `zn hooks install zcode` and `uninstall` are now atomic. The install saves what `hooks.enabled` was before it touches the config and writes `config.json` last, so an install that fails part-way no longer leaves your own hooks switched on with nothing recorded to undo it, and an uninstall that fails keeps its record until the config is restored. The launcher now has its own deadline two seconds under ZCode's hook timeout: a hook that hangs while starting is blocked instead of letting the call run, because ZCode lets a call run when a hook times out, on Windows too: the PowerShell launcher runs the hook with the same deadline and kills it, and everything it started, when it runs out. On macOS and Linux a hook that ignores the first stop signal is killed one second later, and a launcher with no timer available blocks instead of running without a deadline. A failed install or uninstall no longer leaves a backup file behind.
