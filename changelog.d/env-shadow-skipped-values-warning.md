### Changed
- `zn env shadow` and `zn secret import` now say plainly which variables they left in `.env` in clear text: each one is named (never its value), with the reason (too short to tell apart from ordinary settings, multi-line, or a name zn cannot use) and the command to store it anyway, `zn secret set NAME`. A closing line gives the count and says to treat these values as readable by an agent until they are stored with `zn secret set`. With `--dry-run` the line is marked as a preview. When some values stay behind, the first line no longer says the file holds only markers.
