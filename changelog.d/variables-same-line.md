### Security
- The download-and-run and startup-file download checks now read literal variables assigned earlier on the same command line: `X=curl; $X URL | sh`, `S=sh; curl URL | $S`, `T=~/.bashrc; curl URL >> $T`, `X="$(curl URL)"; sh -c "$X"`, `${X}` forms and `export X=...`. Nothing is evaluated: a value is only text copied from an earlier assignment, a variable that was not assigned on the line stays unknown, and benign uses (`X=echo; $X hi`, `S=jq; curl URL | $S .`) stay allowed. A line with more than 256 assignments is refused instead of guessed at; a value longer than 8,192 characters is not kept.
