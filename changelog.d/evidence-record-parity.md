### Fixed
- The Node and Python packages now write the same evidence record for the same event. A confidence of 0 is kept as 0 (Node used to write 1.0), an empty rule or reason is written as null by both (Python used to write an empty string), and a payload that is not text is hashed the same way by both (a missing payload is empty, 0 is "0", false is "false", and non-ASCII text is hashed as UTF-8). A confidence below 0.0001 written by one package no longer fails verification in the other as a false "Tamper detected". Ledgers written by earlier versions of either package still verify.
