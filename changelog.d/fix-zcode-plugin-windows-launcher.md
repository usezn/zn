### Security
- The Windows hook of the ZCode plugin can no longer be replaced by a file in your project on macOS and Linux. Its command was a Windows path, which on those systems is a relative path, and ZCode starts hooks in the project folder, so a file planted in the project at that path would have run as the hook. The command is now a launcher script inside the plugin (`scripts/zn-hook-win.cmd`), an absolute path on every system that only starts on Windows. `zn-gate check` now reports a plugin hook with a relative command, or with the earlier Windows PowerShell path, as not protected on every system, so install the plugin again in ZCode (Settings, Plugins) if you installed an unreleased build.
