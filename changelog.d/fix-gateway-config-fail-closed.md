### Security
- The experimental Rust gateway (not distributed) reads `ZN_ENV` / `environment` in any capitalisation and with spaces around it, and refuses to start on any value other than `development` or `production`. Before, `prod`, `Production` or ` production` quietly skipped the production checks, including mandatory audit encryption.
- The experimental Rust gateway trims and lowercases the hashes in `ZN_POLICY_HASHES` / `engine.allowed_policy_hashes` and skips empty entries, and refuses to start on an entry that is not a 64-character SHA-256 hash. Before, upper case, `, ` separators or a trailing newline made every policy fail its integrity check.
- The experimental Rust gateway refuses to start with an empty audit database path (`ZN_DB_PATH`, `--db-path` or `audit.db_path`). Before, it kept the audit log in a temporary database that was lost when it stopped.
- The experimental Rust gateway treats a blank `ZN_DB_KEY` / `audit.encryption_key` as not set and refuses a passphrase shorter than 16 characters. Before, an empty key turned encryption on with an empty passphrase and passed the production check.
- The experimental Rust gateway no longer creates a policy folder named in `engine.policy_dir` that does not exist: it refuses to start, warns when a named folder holds no policy, and refuses an empty `engine.policy_dir`. Before, a typo started it with no policies and no warning.
