### Changed
- zn-gate now needs Node.js 20.19 or later (22 LTS is recommended). Node.js 18 has been end-of-life since April 2025, and 20.19 is the version the Claude Code plugin and its dependencies already needed, so the npm package, the command line, the hooks and the plugin now share one floor. If you are on an older Node.js, `zn-gate` stops with a message that names the version it needs; install the current LTS from nodejs.org (or run `nvm install --lts`) and run the command again. Hooks, MCP servers and `zn run` commands that an agent has already started keep running on an older Node.js and print a warning instead of stopping.
