### Security
- On Windows, `ZN_HOOK_DIR` was only checked to be a real folder, although the hook launcher kept there runs on every tool call. zn-gate now applies the same rule as on Linux and macOS: it refuses a folder when a link or junction is anywhere in its path, when its owner is not you, SYSTEM or Administrators, or when its access list (or that of any folder above it, up to the drive root) lets other users delete it, replace it or change its permissions (and, for the folder itself, create files in it). A new folder is created private to your account, and the path is checked again after the launcher is written.
