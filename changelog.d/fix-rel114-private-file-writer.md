### Security
- Added a writer and a reader for private files in the Rust core. A private file is created readable only by its owner (mode 0600 on Linux and macOS, a protected owner-only access list on Windows) and is never written through a symbolic link. Reading goes through the same checks on the opened file, so a file swapped for a link between the check and the read cannot be followed. Both fail instead of leaving or accepting a file that other local accounts can read.
- On file systems that cannot store Unix permissions (a Windows drive mounted in WSL, FAT or exFAT, some network shares) creating a private file now fails with a message that says what to do, instead of a bare mode error. A leftover temporary file from a crashed write is removed on the next write in that folder.
