### Security
- The project hook and the fallback of the hook launcher now start `zn` and Node.js only from absolute PATH entries. Before, when the PATH held a relative or empty entry, a `zn` or `node` placed in the repository could run instead (the project hook on macOS and on Linux systems where `sh` is bash), and on Windows `zn.cmd` could start a `node.exe` or `node.bat` from the current folder. If you installed a 1.14.0 release candidate, run `zn hooks install` again (and `zn hooks install --project` in each project that uses a project hook) so the written hooks get the fixed guard.
