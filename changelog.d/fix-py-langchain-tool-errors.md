### Security
- Python, LangChain: `guard_langchain_tool` now checks and masks the message of an exception raised by the tool, as it does the tool output, because LangChain (`handle_tool_error`) and LangGraph (`ToolNode(handle_tool_errors=True)`) send that message to the model. A blocked message is handled like a blocked output; a message with a secret is raised again as the same exception type carrying only the masked message. Before, a secret or injected text in a tool error reached the model.
- Python, LangChain: `ZnGuardCallbackHandler` now has `on_tool_error`: when a tool's error message is blocked, or contains a secret while `mask_secrets=True`, the error is replaced by `GuardBlockError`, because a callback cannot rewrite it. Before, the handler did not look at tool errors.
