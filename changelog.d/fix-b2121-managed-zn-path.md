### Security
- `zn team managed-config` has a new option, `--zn-path`, that makes the managed hooks run zn at one absolute path instead of the first `zn` on each developer's PATH. Before, a program named `zn` placed earlier on the PATH that always answered "allowed" turned the managed hook into allow without editing any settings file. The command refuses a path that is not absolute, does not exist or cannot run on this computer, or sits in a folder a user can write to. Without the option the printed files are unchanged and now carry a note that recommends it; the guide says what the managed install does and does not protect.
