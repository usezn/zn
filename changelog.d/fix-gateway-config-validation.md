### Security
- The experimental Rust gateway (not distributed) refuses to start on an unusable `security.allowed_origins` / `ZN_ALLOWED_ORIGINS`: an empty value or `,` now means loopback origins only (before, it allowed an empty `Origin`, so a WebSocket upgrade with no `Origin` header got through), and `*` or an entry that is not an origin stops the start with a message instead of a panic.
- The experimental Rust gateway refuses a `siem.endpoint` / `ZN_SIEM_ENDPOINT` that is not an `http://` or `https://` URL at start (an empty value means no export), and an unknown `kms.kms_type` / `ZN_KMS_TYPE` (only `local` and `aws` exist). Before, a bad endpoint failed at the first event and an unknown KMS type quietly kept the key on the local machine.
- The experimental Rust gateway refuses `NaN`, infinite, negative and out-of-range values for `neural.threshold`, `neural.classifier_threshold`, `fusion.tau` and `guardrails.fpr_margin`, a `guardrails.paranoia_level` / `ZN_PARANOIA_LEVEL` outside 1 to 5, and a variable it cannot read. Before, a bad variable was ignored, `0` was raised to 1 and a level of 6 or more was treated as balanced.
- The experimental Rust gateway refuses `consensus.enabled` with no critical tool, trims spaces around critical tool names, requires the settings file to be a JSON object (a JSON array skipped the unknown-key check), and logs which settings file it loaded from the current folder, with a warning when it turns protections off.
