### Added
- The evidence log can now say which check blocked an action. A block recorded by an agent hook carries an optional `rule_id` such as `destructive:rm_root_home`, `secret-file:dotenv`, `secret-file:credential`, `egress-check` or `size:command-too-long`, next to the existing `rule`. Only an id from the fixed list the hooks emit is stored; any other value is dropped. It holds only the id, never a command or a path. Older records without it still load and verify.
