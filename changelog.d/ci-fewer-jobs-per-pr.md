### Changed
- CI: a pull request into `next` now starts about half as many jobs. It runs the required checks on Ubuntu (Node.js 18.x, 22.x and 24.x, Python 3.12, both package builds), one lint job (eslint, ruff and mypy together) and the workflows its paths call for. macOS runs only for changes to code with macOS-specific behaviour; the plugin checks and public facts only for the files they read; the dependency audits only on pushes and every day. The MCP smoke joins the examples smoke in one job. The full matrix still runs on pushes to `main` and `next`, on pull requests into `main` and release branches, with the `full-ci` label, on manual runs and now every day.
