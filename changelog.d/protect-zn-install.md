### Security
- Agents can no longer switch zn off by changing its own files or removing it. The hooks now refuse writes to the Claude Code plugin files, to the installed zn-gate package (a single write over the hook code, such as `lib/hooks/policy.js`, would change every check) and to a fake `zn` or `zn-gate` in a folder on your PATH. They also refuse `npm uninstall -g zn-gate`, `pip uninstall zn-gate`, `claude plugin disable zn-gate` and `claude plugin marketplace remove usezn`, however the name is spelled (`z''n-gate`) and also when it comes from a variable, a substitution or `xargs`: run those yourself in your own terminal. Reading these files, work in a source checkout of zn-gate, and mentioning these commands in a message or a document are unchanged.
