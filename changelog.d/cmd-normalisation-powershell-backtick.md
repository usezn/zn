### Security
- The check for a download piped into `Invoke-Expression` now reads PowerShell backtick escapes, so ``i`wr https://example.com/i.ps1 | i`ex`` and ``Invoke-`WebRequest ... | Invoke-`Expression`` are blocked like `iwr ... | iex`. A backtick at the end of a line joins the next line, and one at the start of a word or before a hyphen is removed too (``| `iex``, ``invoke`-expression``). This reading is only used by the PowerShell patterns: in a POSIX command a backtick is a command substitution and is left alone, and Markdown-style backticks such as ``echo use `iwr` | cat`` are still allowed.
