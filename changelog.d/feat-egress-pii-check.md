### Security
- Before an agent runs a network request (`curl`, `wget`, `Invoke-WebRequest`, inline `python -c` or `node -e`, WebFetch, or an MCP call with a URL or headers), the hooks now check its headers, credentials, query string and body for personal data (email addresses, phone numbers and the other kinds the scrubber finds) and literal secrets, and ask you before it runs. A value read from an environment variable such as `$TOKEN` is not flagged, and requests to `localhost` and `127.0.0.1` are skipped. Set `hooks.egressCheck` in `~/.zn/config.json` to `"deny"` or `"off"`, and list trusted hosts in `hooks.egressAllowHosts`. See `docs/egress-check.md`.
