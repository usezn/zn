### Security
- `zn team managed-config` has a new option, `--node-path`, to use together with `--zn-path`. The managed hook then runs Node.js only from that exact absolute path and blocks the action if `node` resolves to anything else. Before, when Node.js was not installed next to zn, a program named `node` placed earlier on the PATH still ran instead of the real one. The path is checked like `--zn-path` (absolute, exists, runs, not in a folder a user can write to, no group or world write); for another system only its shape is checked. `--node-path` without `--zn-path` is refused.
