### Security
- On Windows, the gateway no longer starts a `npx` or `uvx` shim found in a project folder when it is started from a subfolder of the project. Besides the folder it runs in, it now treats as untrusted, when it looks through the PATH, the nearest folder above it that holds a `.git` folder or file, and any other such folder up to eight levels above that one. A `.git` in your home folder or above it does not count, because a home folder kept as a git work tree (dotfiles) is not a project: in that case, a project without a `.git` of its own has only the working folder treated as untrusted. If the gateway is started in your home folder itself, it treats no folder as untrusted, so `PATH` folders under your home folder are searched. If the gateway cannot check, it treats the working folder and every folder above it as untrusted.
- On Windows, the gateway now ignores any PATHEXT entry that is not a plain ending (a dot and up to 8 letters or digits), so an entry with a path separator or `..` can no longer make a command name point outside its PATH folder. It also checks that the real path of the program it found stays inside that PATH folder and outside the project.
