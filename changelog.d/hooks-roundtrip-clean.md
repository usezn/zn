### Fixed
- `zn-gate hooks uninstall` now gives back the agent settings file as install found it when nothing else changed in it: a one-line JSON file keeps its format, an empty `{}` that was there before stays, and a file that install created is deleted instead of being left as `{}` (or as an empty skeleton for Cursor, Codex, Copilot and Antigravity). If you changed other settings after install, only zn's entries are removed, as before. The first install keeps the original (a `.bak-zn-original` copy, or a `.bak-zn-original-absent` marker) next to the file, later installs never overwrite it, and uninstall removes it. A config installed by an older version has no such copy: uninstall uses an older backup if one is still there, and otherwise removes only zn's entries (Antigravity and Copilot still delete a file that has nothing else left).
- zn keeps the three newest `.bak-zn-*` backups of each agent settings file, besides the original, and two backups taken in the same second no longer overwrite each other.
