### Security
- The download-into-a-startup-file check (the `rc_download` rule, which is off by default in the hook) now refuses a target whose name is written as a glob or built by a substitution. `>> ~/.bas?rc`, `>> ~/.bashr[c]` and `-o /etc/prof*` are refused when the glob could match a protected startup name (read without regard to case), and `~/.$(echo bashrc)`, `~/.${X}rc` or `/etc/$(echo profile)` are refused when the name sits in the home folder or in a startup folder (`~/.ssh`, the fish and `environment.d` folders, `/etc`, `/etc/profile.d`), because the name cannot be told. Before, these spellings were allowed. Globs that cannot match a startup name (`~/Downloads/*`, `~/.bashrc?`) and substitutions in other folders stay allowed. The hook, the Node.js library and the Python library give the same verdict.
