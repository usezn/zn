### Fixed
- On Windows, `zn hooks install claude-code` writes a hook command that Git Bash, PowerShell and cmd.exe all run. Claude Code uses PowerShell when Git for Windows is not installed, and the single-quoted command zn wrote before only worked in Git Bash, so `PreToolUse` did not run there. The command is now one `powershell.exe` call with the same steps as the launcher script on macOS and Linux: it runs the Node.js zn was installed with, else `zn` from your PATH, else it blocks the call. `zn-gate check` reads the new form, and run `zn hooks install claude-code` again to replace the old one.
- With an npm-installed Claude Code on Windows (`claude.cmd`), `zn hooks install claude-code` now registers its MCP server itself, running `claude.cmd` through the system cmd.exe, instead of asking you to paste a long command. If that is not possible, it prints a short `claude mcp add` command that uses zn's own copy of zn-gate, not the temporary `npx` folder, and works in cmd.exe, PowerShell and Git Bash.
