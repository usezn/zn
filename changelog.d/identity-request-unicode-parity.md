### Fixed
- The identity-request rules (pi:identity_request and pi:identity_request_multi) now give the same result in the Node and Python packages on text with folded letters such as the long s, the Kelvin sign and the dotless i: before, one package flagged text the other let through when the raw text was checked. The raw-text rule gives the same result in both packages; the normalised text, where the dotless i and the dotted capital I read as i, is still checked, so texts that use them are still flagged. A test in both packages pins this.
