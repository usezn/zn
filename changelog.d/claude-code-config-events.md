### Added
- `zn hooks install claude-code` also registers the Claude Code hooks `ConfigChange` and `InstructionsLoaded`. `ConfigChange` blocks a change that would take effect during the session when a project or local settings file now has a critical `zn audit` finding, or a skill file now holds text that tries to instruct the agent (your own user settings and managed policy settings are not blocked). `InstructionsLoaded` records in the evidence log an instruction file (`CLAUDE.md`, `.claude/rules/*.md`) that holds such text, because Claude Code cannot hold it back. Run `zn hooks install claude-code` again to add them.
