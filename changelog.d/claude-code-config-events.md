### Added
- `zn hooks install claude-code` also registers the Claude Code hooks `ConfigChange` and `InstructionsLoaded` (the plugin does not). `ConfigChange` blocks a change to a project settings file that adds a critical `zn audit` finding the file did not have before in the session, and a change to a skill file that adds text a person cannot see (Unicode tag characters or bidirectional overrides); your own user and local settings and managed policy settings are not blocked, and a skill that quotes a prompt-injection example is allowed. `InstructionsLoaded` records one notice per session and file in the evidence log for an instruction file (`CLAUDE.md`, `.claude/rules/*.md`) that holds text trying to instruct the agent, because Claude Code cannot hold it back; it is not counted as blocked. Run `zn hooks install claude-code` again to add them.
