### Added
- `zn audit` reports an instruction file (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursorrules`, rules, `SKILL.md` and other skill, command and agent files) that has a run of 40 or more empty or whitespace-only lines with more text after it (new rule ZNA021, medium). That text is out of view for a reviewer and past the part of the file a classifier reads. The finding gives the line where the text starts and the length of the run, and never prints the text. `AUDIT_RULES_VERSION` is `2026-10-23.1`.
- The local rules read a run of empty or whitespace-only lines as a single empty line before they run, in Node.js and in Python, on prompts and on tool results. Text that follows a long run of padding is now checked together with the text before it, instead of falling outside the part that is scanned. Lines made only of Unicode spaces (no-break, em, ideographic, line and paragraph separators, next line, soft hyphen) count as empty too. The audit rule ZNA021 also flags the supporting files of a skill, such as templates. `RULES_VERSION` is `2026-10-23.9`.
