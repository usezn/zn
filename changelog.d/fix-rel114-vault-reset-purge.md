### Security
- `zn vault reset` keeps an encrypted backup and says where it is. The new `zn vault purge` is the separate way to delete a vault for good: it lists every file it will delete (the vault, project token maps, the audit log, every backup and the session key), asks you to confirm (`--yes` for scripts, never for an AI agent), deletes them and checks that none is left. It no longer reports success while a file or the system keychain entry remains, and `zn-gate uninstall` now removes backups and token maps too and says what is left.
